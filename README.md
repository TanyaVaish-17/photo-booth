📸 K-Click Booth

A modern, stylish, and interactive Photo Booth Web App that lets users capture, customize, and preserve aesthetic photo strips with a smooth and delightful user experience.

🔗 Live Demo: https://k-click-booth.vercel.app/
 
🔗 GitHub Repo: https://github.com/TanyaVaish-17/photo-booth

✨ Features

📷 Interactive Photo Capture
Capture photos directly using your webcam.
🎨 Customization Options
Apply layouts, frames, filters, and stickers in real-time.
🖼️ Live Preview
Instantly preview your photo strip before capturing.
🧩 Quick Templates
Choose aesthetic pre-designed templates.
📁 Result Page
View, edit, retake, and download final output.
💖 Memories Page (NEW)
Save and revisit your past photo strips in a beautiful gallery.
📱 Responsive Design
Works seamlessly across all devices.

🛠️ Tech Stack

Frontend: React, Vite, JavaScript, Tailwind CSS
Routing: React Router
Deployment: Vercel

🚀 Getting Started

Prerequisites
Node.js installed
Installation
git clone https://github.com/TanyaVaish-17/photo-booth.git
cd photo-booth/frontend
npm install
npm run dev

🌐 Deployment

Deployed using Vercel:

1. Push code to GitHub
2. Import project in Vercel
3. Select frontend as root
4. Deploy 🚀
